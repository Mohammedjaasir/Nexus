# Changelog

All notable changes to Nexus are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased] — Nexus Phase A

### Added

- The Nexus shell: top bar with search, theme and settings; a sidebar with
  Home, Workspaces, Projects, Artifacts, Handoffs and Deployments; and Files,
  Agents, Integrations and Settings.
- The launcher, "What are you working on?", with eight workspaces and
  *Your Projects*, keyboard navigation, and real recent projects.
- Workspace, project and planned pages, driven by a workspace registry.
- The assistant panel, connected to the lead agent with workspace and project
  context.
- A command palette (<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>K</kbd>) and an assistant
  shortcut (<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>J</kbd>).
- Responsive layouts: full sidebar, icon rail with an assistant sheet, and a
  bottom bar on small screens.

### Changed

- New visual identity; the previous product name was removed from the app's
  text, docs and build display names.
